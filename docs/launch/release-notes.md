# Release notes contract

No public DuckOS release has been published. This is the release documentation
format, not a draft announcement or an assertion that 1.0.0 is ready.

Every release record includes version, date, exact commit, signed artifact
digests, supported architectures/platforms, important features, fixes, security
changes, breaking changes, upgrade instructions, recovery path and known issues.
Qualification evidence must support each availability claim. Security details
follow coordinated disclosure; notes must never include credentials or exploit
material that has not been approved for publication.

Upgrade instructions identify compatible source versions, migration behavior,
required free space and Active/Previous rollback limitations. The same reviewed
record supplies future RSS/Atom entries and changelog pages, with canonical URLs
and actual publication timestamps. Empty feeds must not contain invented releases.

The first public product version is 1.0.0 only after the
[release gate](../product-spec-1.0.md) and explicit launch approval. Internal build
identifiers are not public releases. See [update architecture](../update-system.md).
