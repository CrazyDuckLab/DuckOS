# Community conduct

DuckOS welcomes technical questions, bug reports and constructive disagreement.
Treat contributors and users with respect. Discuss behavior, evidence and tradeoffs;
avoid personal attacks, harassment, discrimination, threats and unwanted contact.

Keep issues and pull requests relevant to the project. Provide reproducible,
sanitized evidence and respect maintainer decisions about scope and safety.
Do not publish another person's private information, credentials or sensitive
network details. Vulnerability reports follow [SECURITY.md](SECURITY.md).

Repository maintainers may edit or remove inappropriate content, close disruptive
threads or restrict participation using GitHub moderation tools. They should
apply these standards consistently and explain decisions where doing so is safe.

To report a conduct concern, use GitHub's reporting tools or request a private
contact channel from the repository maintainers without posting sensitive details.
There is no dedicated staffed conduct-response service or guaranteed response time.

This policy applies to DuckOS repository issues, pull requests and discussions.
